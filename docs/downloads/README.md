# Downloads da Calculadora de Treliças

Arquivos esperados para publicação do site:

- `CalculadoraTrelicas-windows.zip` — copiado de `build/CalculadoraTrelicas-windows.zip`.
- `CalculadoraTrelicas-linux.zip` — copiado de `build/dist/CalculadoraTrelicas-linux.zip`.
- `CalculadoraTrelicas-macos.zip` — pacote `.app` para macOS com runtime Java embutido.

No macOS, extraia o ZIP e abra `App_CalculoDeTrelica.app`. Caso o sistema bloqueie por segurança,
use o botão direito no aplicativo, selecione `Abrir` e confirme a execução.
